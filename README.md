# Explore Uganda - Tourist Guide

A web application to help tourists discover Uganda's top attractions. Features dynamic filtering, a detailed attraction view, a favorites system (localStorage), and an itinerary planner with cost calculation and export.

## Features
- Dynamic attraction listing with filtering (Category, Location, Price)
- Detailed pages with map integration
- Favorites system using localStorage
- Itinerary builder with total cost calculation and export to .txt
